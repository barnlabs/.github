# BarnLabs

BarnLabs LLC makes products. The public studio is [barnlabs.net](https://barnlabs.net).

**MikeNet** is the current public product: household energy-cost calculators at [mike-net.top](https://mike-net.top). Arithmetic stays in the browser.

Client websites, custom software, and practical AI work are offered under the **NeoRome** label at [neorome.dev](https://neorome.dev). Contracts, invoices, and payments stay with BarnLabs LLC. NeoRome is not a separate company.

Most company source is private. That is a working choice, not a claim that every experiment is a shipping product.
